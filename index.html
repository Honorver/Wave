Перенос плейлиста из Яндекс Музыки
Как перенести музыку из Яндекс Музыки в Wave?

Способ 1 — перенести список песен

  1. Открой Яндекс Музыку и нужный плейлист.
  2. Подготовь список композиций в формате Исполнитель — Название, по одной песне в строке. Можно вручную скопировать названия или воспользоваться инструментом экспорта списка, которому ты доверяешь.
  3. Вставь список в поле ниже либо сохрани его как .txt и нажми «Загрузить TXT / CSV».
  4. Нажми «Импортировать и найти треки». Wave создаст плейлист из совпадений, найденных в Audius.

Способ 2 — перенести сами аудиофайлы

Если у тебя уже есть обычные MP3/M4A/FLAC/WAV-файлы, которые ты вправе использовать, их можно будет добавить через отдельную функцию локального импорта аудио. В этой версии Wave такая загрузка ещё не реализована.

Важно: скачанные для офлайн-прослушивания треки внутри приложения Яндекс Музыки не являются обычными MP3-файлами. Wave не умеет извлекать их или обходить защиту. Список песен не гарантирует наличие аудио в Audius.

Импортируй список песен из TXT/CSV или вставь его вручную. Wave попробует найти совпадения в Audius и создаст новый плейлист. Аудиофайлы из Яндекса не копируются.

Ссылка на плейлист Яндекс Музыки сама по себе не позволяет Wave получить список песен: для этого нужен доступ к данным сервиса. Экспортируй названия в файл или вставь их сюда. Поиск может не найти некоторые композиции.

Подключение Audius

Если сервер возвращает 403, попробуй бесплатный API-ключ Audius. Ключ хранится только в браузере. Не вводи секретный Bearer Token.
